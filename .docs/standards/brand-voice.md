# Brand Voice, Tone & Copywriting Guidelines

> **Status: skeleton.** Structure + explainers only. Every `[FILL]` marks a slot a
> future brand replaces. Keep the headings; they map to where copy decisions live.

## What / Why

A single reference for how the brand writes across product, blog, UX, and legal
surfaces. Prevents tone drift as more authors and AI agents touch the copy.

Usage: read before writing any customer-facing text. When a rule below is filled
in, it is binding; when a slot is empty, ask the brand owner rather than inventing.

## 0. The One Rule

Define the single principle that overrides everything. Usually a "show, don't tell"
rule: never name the brand's values, write the behavior and let the reader feel it.

- `[FILL]` The one rule, in one sentence.
- `[FILL]` The litmus test authors run on every sentence.

## 1. Core Philosophy

The brand's stance on its product, market, and customers. Non-negotiable beliefs.

- `[FILL]` 2–4 core beliefs the brand will not compromise on.
- `[FILL]` What "good" looks like for this brand vs the category norm.

## 2. How We Sound

Behavioral traits, described as actions — not adjectives like "friendly". Each
trait should read "we do X, not Y".

- `[FILL]` 3–5 behaviors with a do/don't pair each.
